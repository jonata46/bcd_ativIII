Livraria Página Viva – Banco de Dados

Atividade III – SEDUC DEST2.

Banco de dados relacional de uma livraria online fictícia, com catálogo (livros, autores, editoras e categorias), clientes e vendas (pedidos, itens e notas fiscais). O modelo está normalizado até a 4FN e tem 11 tabelas.

Arquivos:

livraria_pagina_viva.sql	Cria o banco, as tabelas e insere os dados
consultas_livraria.sql	15 consultas de exemplo
livraria_pagina_viva_dump.sql	Dump (estrutura e dados) gerado com mysqldump
